AdderSuite overview

  • Purpose: Structured C++ project demonstrating layered design with testing, coverage, logging, and CI/CD.
  • Layers:
    • Interfaces: IAdder contract.
    • Domain: Adder logic with overflow check.
    • Factory: Dependency injection (Real/Stub).
    • C-API: extern "C" facade.
    • Logging/Error: Minimal cross-cutting concerns.
  • Tests: GTest + GMock for real, stub, mock, and C-API.
  • Benchmarks: Google Benchmark target.
  • Coverage: gcovr HTML report via CMake target coverage.
